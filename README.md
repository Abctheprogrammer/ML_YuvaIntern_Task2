# Week 2 Task: Supervised Machine Learning Models

This project demonstrates supervised learning using Scikit-learn with one regression task and one classification task.

## Models
- Regression: Linear Regression and Random Forest Regressor on the Diabetes dataset.
- Classification: Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors (KNN) on the Breast Cancer Wisconsin dataset.

## Setup (Windows)
1. Install Python 3.10 or newer (Python 3.11/3.12 recommended for broad library compatibility).
2. Open Command Prompt or VS Code terminal inside this project folder.
3. Create a virtual environment:
   `python -m venv .venv`
4. Activate it:
   - Command Prompt: `.venv\\Scripts\\activate`
   - PowerShell: `.venv\\Scripts\\Activate.ps1`
5. Install packages:
   `python -m pip install --upgrade pip`
   `python -m pip install -r requirements.txt`
6. Run:
   `python src/train_models.py`

The script downloads standard datasets through Scikit-learn's dataset loader if not already cached. An internet connection may be needed the first time. Outputs are saved in `outputs/`.

## Evaluation approach
- 80/20 train-test split with a fixed random seed for reproducibility.
- Classification metrics: accuracy, precision, recall, F1-score, and confusion matrix.
- Regression metrics: MAE, RMSE, and R².
- Scaling is applied in pipelines for Logistic Regression and KNN to avoid leakage: the scaler is fitted only on training data.

## Notes
Metrics can vary slightly with library versions. Use the actual generated CSVs/plots in the report rather than claiming results that you did not run locally.
