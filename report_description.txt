This report presents the implementation and evaluation of supervised machine learning models using Python and the Scikit-learn library. The main objective is to understand how regression and classification algorithms learn from labelled data, generate predictions, and can be compared using suitable performance metrics.

Two standard datasets provided by Scikit-learn are used. The Diabetes dataset is used for a regression task, where models estimate a continuous target value. Linear Regression provides a simple baseline that models a linear relationship between input features and the target. A Random Forest Regressor is also trained to examine whether an ensemble of decision trees can capture more complex patterns. Regression performance is assessed using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and the coefficient of determination (R²).

The Breast Cancer Wisconsin dataset is used for binary classification. Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors (KNN) models are trained to predict one of two target classes from numerical diagnostic features. The data is split into training and testing subsets so that the evaluation is performed on data not used to fit the models. Feature scaling is included in pipelines for algorithms that are sensitive to feature magnitude, and the scaler is fitted only on the training data to reduce data leakage. Classification models are compared using accuracy, precision, recall, F1-score, and confusion matrices.

The project includes a reusable Python script, dependency file, README instructions, metric tables, prediction files, and visualisations generated during execution. A fixed random seed makes the train-test split reproducible. The comparison helps demonstrate that no single algorithm is best for every problem: model selection depends on the dataset, evaluation metric, interpretability, and the cost of different prediction errors. This is an educational demonstration using public benchmark datasets and should not be used for real medical diagnosis. The results should be verified by running the script in the target environment before final submission.
